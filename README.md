# Rust Crates — мод для Minecraft 1.12.2 (Forge)

Ящики в стиле Rust: **обычный (деревянный)**, **элитный (зелёный)**, **военный**, а также их **ADMIN-версии** с красной надписью ADMIN.

## Как пользоваться
1. Возьмите ящики во вкладке креатива **Rust Crates** и расставьте обычные (не ADMIN) ящики по карте.
   Каждый поставленный ящик сам попадёт в список своего типа (с координатами).
2. Поставьте в любом месте ADMIN-ящик нужного типа (обычный / элитный / военный).
3. **ПКМ** по ADMIN-ящику: открывается пул лута (27 слотов). Положите туда предметы, которые могут выпадать.
   Количество в стаке = максимальное количество при выпадении.
4. **Shift + ПКМ** по ADMIN-ящику: открывается панель управления:
   - **Лут** — шанс выпадения каждого предмета (0–100%).
   - **Ящики** — все поставленные ящики этого типа с координатами; для каждого включается или выключается спавн лута, кнопка ТП телепортирует к ящику.
   - **Настройки** — автоспавн вкл/выкл, интервал, очистка ящика перед спавном, случайное количество, лимит предметов, кнопка «Заспавнить лут сейчас».
5. Игроки открывают обычные ящики через **ПКМ** (27 слотов, как в сундуке).

Права: панель и пул лута доступны только операторам (уровень 2+) или игрокам в креативе.
В выживании ящики не ломаются, убрать их можно в креативе.

## Сборка через GitHub
1. Загрузите содержимое архива в новый репозиторий GitHub.
2. Откройте вкладку **Actions**: сборка «Build mod» запустится сама (или нажмите **Run workflow**).
3. Когда сборка закончится, скачайте артефакт **rustcrates-mod**: внутри будет jar-файл мода. Положите его в папку mods.

Локально: Java 8 + Gradle 4.10.3, команда gradle setupCIWorkspace build.
